# zizmor, the workflow-safety half of the gate on the gates. Hash-pinned
# because a linter that runs before every other check is a supply-chain
# position worth defending.
#
# The pin lives here and not in tests.yml's `run:` block because Dependabot's
# `pip` entry reads manifest files and never a workflow: a version written
# into a step is a version nobody is ever told to move.
#
# WHAT THE HASH LIST IS. Every artifact the pinned release ships, not the
# runner's subset, so the file resolves on whichever platform lifts it.
# Dependabot rewrites it the same way: it replaces the version and
# regenerates the WHOLE artifact set from the release, so after a bump the
# list is a superset of what any single runner needs and `--require-hashes`
# selects the right artifact out of it.
#
# THE TEST IN tests/_wfpins.py requires one exact `==` pin for zizmor,
# at least one sha256 hash, and distinct digests compared case-insensitively.
# --hash accepts only attached =value, validated as lowercase sha256: plus
# 64 hex digest characters in either case. --config-settings accepts
# =KEY=VAL or a following KEY=VAL token. Other tokens and missing/invalid
# values fail.
# Hashes come from that same option walk. Unfinished nonempty continuation
# runs are refused too. The hash count is
# free to move: a release can gain or lose artifacts on a valid bump.
#
# NOTHING ELSE IS PINNED HERE. zizmor 1.29.0 declares no Requires-Dist at all
# and holds no .py file that imports yaml, so its transitive closure is EMPTY
# and this manifest carries one requirement: the actionlint job is a Go
# binary unpacked from a tarball and needs no Python, and the suites that do
# import yaml get PyYAML from requirements-test.txt, which is a separate
# install. A pin nothing resolves is not a parity decision — it is one
# artifact's hash set to keep correct by hand.
#
# TO MOVE THE PIN BY HAND — the fallback when Dependabot cannot resolve a new
# version's hashes and opens no pull request, leaving the pin where it is:
#
#     python3 -m pip download -d /tmp/req-dl zizmor==<new>
#     sha256sum /tmp/req-dl/*
#
